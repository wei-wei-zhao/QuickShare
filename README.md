# QuickShare 下载

**扫码传文件**：手机和电脑连同一 WiFi，安装后扫码即可传截图/图片/文件。

## 下载哪个？

| 文件 | 说明 |
|------|------|
| [PhoneToPC-Setup.zip](./PhoneToPC-Setup.zip) | **推荐**。解压后双击 `安装.bat`，可自选安装目录 |
| [PhoneToPC-Portable.zip](./PhoneToPC-Portable.zip) | 解压即用，运行 `PhoneToPC.exe` |

## 使用步骤（安装包）

1. 下载并解压 `PhoneToPC-Setup.zip`
2. 双击 **安装.bat**，选择安装位置，输入 `Y` 确认
3. 桌面打开「PhoneToPC 扫码传文件」
4. 手机扫电脑面板上的二维码上传（需同一 WiFi）
5. 若手机打不开，在安装目录右键管理员运行 **放行防火墙.bat**
